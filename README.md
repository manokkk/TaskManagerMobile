# Task Manager Mobile

React Native (Expo) app with TypeScript and NativeWind (Tailwind CSS).

## Features

- 📱 Mobile-optimized UI with Tailwind CSS / NativeWind
- ⚡ Real-time status tabs (All, Pending, In Progress, Completed) with counters
- 🔍 Instant title and description search
- ➕ Create Task sheet with priority (Low, Medium, High) and initial status
- 🔄 Offline fallback preview mode with instant toggle and delete
- ⚙️ Dynamic API Configuration popup to connect to backend on emulator, simulator, or physical phone

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Start Expo dev server
npm start
```

Press:
- `a` to open in Android Emulator
- `i` to open in iOS Simulator
- `w` to open in Mobile Web Preview
- Or scan the QR code with **Expo Go** on your physical iOS or Android phone!
